Port notes

The WebGL fragment shader in this file is the reference. For parity, port it to a Metal [[stitchable]] colour effect used from SwiftUI (.colorEffect(ShaderLibrary.orb(...)), macOS 14+) or an MTKView. Drive every uniform from one CADisplayLink/TimelineView(.animation) tick. The Core Animation layer stack below is the fallback approximation (loses domain warp and the silk bands, keeps everything else).

Per-state parameters (sRGB hex, used directly, no linearisation)

Global constants

  • Orb radius R = 0.58 x half-canvas (big, 240 px orb in a 400 px box), 0.64 x half-canvas in the pill (28 pt orb in a 44 pt box). Radius scale = 1 + breath*sin(breathPhase) + 0.09*level.
  • Motion phase is integrated, never time*speed: phase += dt*(speed + levelSpeed*level); breathPhase += dt*breathRate. This is what keeps state changes from jumping.
  • Lobes (4): lobe i orbits at angle t = phase*(0.55+0.17i)*(i odd ? -0.8 : 1) + 1.7i, centre rad*(cos t, sin(1.07t + 0.6i)), rad = 0.40 + 0.16 sin(0.43 phase + 2.3i) + 0.10 level, gaussian sigma 0.42 + 0.08 sin(0.61 phase + 1.9i) + 0.14 level (all in units of R). Additive accumulate, then tone map 1 - exp(-acc*glow), then saturation 1.3 around Rec.601 luma.
  • Swirl: rotate sample point by swirl*1.4*(1 - smoothstep(0,1.2,d)) rad (stronger near centre). Domain warp: two simplex octaves at freq 1.3, drift 0.17 to 0.23 per phase unit, amplitude 0.18 + 0.22 level + 0.10 swirl.
  • Silk bands: contours of a curved field, f = noise(0.8w + drift(0.07,-0.05)*phase) + 0.45 dot(w,dir), silk = 0.5+0.5 sin(5f + 0.6 phase), dir rotates at 0.12 rad/phase; squared, then multiplies lobes by mix(1, 0.55 + 1.1*silk^2, silkAmt). Plus a wash: mean lobe colour x 0.22 x exp(-1.2 d^2).
  • Core flash: white-tinted gaussian exp(-3.5 d^2) * level * core.
  • Body: dark #090A11 alpha 0.82, light #F9F9FB alpha 0.60. Glow composites over it premultiplied: rgb = glow + body*(1-max(glow)).
  • Edge: smoothstep feather of 1.8 px + 0.015 R. Edge falloff of lobe light to 0.8 beyond 0.55 R.
  • Specular: white gaussian at (-0.32 R, +0.42 R), exp(-5 r^2), alpha 0.20 (x0.6 in light). Rim: smoothstep(0.78,1,d)*0.22, colour = 50/50 white and the lobe-2/3 mean. Both scale by life.
  • Halo: hue = mean of the 4 lobe colours normalised to max channel 1. Intensity (halo + haloGain*level) * exp(-((r-0.92R)/w)^1.3), w = R*(0.28 + 0.35 level), faded to 0 between 0.82 and 1.0 of the canvas half-size, capped 0.9. Light theme adds a soft contact shadow, black alpha 0.10*exp(-(r-R)/0.12R).
  • Dither: +/- 0.5/255 hash noise on the final colour (kills banding in the halo).
  • Level smoothing: one-pole, a = 1 - exp(-dt/tau), attack tau = 0.045 s, release tau = 0.20 s.
  • Mic: 1024-sample frames, RMS, dBFS = 20 log10(rms), map -55 dBFS to 0 and -15 dBFS to 1, clamp. Disable echo cancellation, noise suppression, and AGC for the meter tap.
  • State crossfade: every scalar and every colour channel eases with the same one-pole, tau = 0.35 s (about 1 s to settle). Theme crossfade the same.
  • Level routing: level = you*userVoice + amb*ambient + tts*claudeVoice + pulse*(0.5+0.5 sin(2.4 t)), each weight crossfaded with the state.

Core Animation fallback stack (back to front)

  1. Halo: circle CALayer, diameter 1.5 R, fill = halo hue, opacity halo + haloGain*level, Gaussian blur radius 0.35 R*(1+0.6 level) (CAFilter gaussianBlur or NSVisualEffect-free shadowRadius on a clear-filled path), transform scale 1 + 0.08 level.
  2. Body: circle, colours above.
  3. Lobe container: masked by a circle (feather via 1.5 px blurred mask), compositingFilter = "plusL" on children.
  4. 4 lobe layers: CAGradientLayer(type: .radial), colour to clear, diameter 2*sigma*R*1.6, blur 0.25 R, positions from the lobe orbit formula above, updated per frame.
  5. Specular: radial gradient white 0.20 to clear, diameter 0.9 R, centre (-0.32 R, -0.42 R in flipped coords), plusL.
  6. Rim: ring CAShapeLayer stroke 0.12 R, white 0.18, blur 0.06 R, masked to the disc.
